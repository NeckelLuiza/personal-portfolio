# Personal Portfolio

Portfólio pessoal desenvolvido com **HTML, CSS e JavaScript** para apresentação de projetos, experiências, habilidades e informações profissionais.

O site possui navegação dinâmica entre diferentes seções e layout responsivo para diferentes tamanhos de tela.

## Funcionalidades

* Apresentação pessoal e profissional
* Seção de projetos
* Seção de currículo e formação
* Links para GitHub e LinkedIn
* Navegação dinâmica entre seções
* Layout responsivo

## Tecnologias

* HTML
* CSS
* JavaScript

## Contexto

Projeto desenvolvido como **avaliação da disciplina de Front-end** durante a graduação em Ciência da Computação, aplicando conceitos de estruturação de páginas, estilização, responsividade e interatividade com JavaScript.
